## Getting Started: Local Development Setup

Relevant source files

This page provides a comprehensive guide for engineers to set up the PeerComp platform on a local development machine. The setup involves configuring a shared infrastructure layer (Backbone), establishing a local Trusted Root Certificate Authority (CA), and initializing the microservices within the pnpm monorepo.

## Prerequisites

Before starting, ensure the following tools are installed:

- Node.js (v20+ required for and modern crypto) [memory-bank/techContext.md#164](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/memory-bank/techContext.md?plain=1#L164-L164)
- pnpm (v10.33.2 recommended for workspace support) [memory-bank/techContext.md#6](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/memory-bank/techContext.md?plain=1#L6-L6)
- Docker & Docker Compose (For infrastructure services) [memory-bank/activeContext.md#76](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/memory-bank/activeContext.md?plain=1#L76-L76)
- mkcert (Recommended for local TLS management)

## 1\. Dependency Installation

The repository uses workspaces to manage dependencies across the five applications and shared packages. Turborepo orchestrates the build pipeline [memory-bank/techContext.md#7-8](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/memory-bank/techContext.md?plain=1#L7-L8)

```shellscript
# Install all dependencies from the root directorypnpm install
```

## 2\. Infrastructure Setup (Backbone)

The directory contains the core infrastructure required for all other services to communicate, including the MongoDB database and the Nginx reverse proxy [memory-bank/techContext.md#144](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/memory-bank/techContext.md?plain=1#L144-L144)

### Docker Stack

Run the backbone stack to start the database and proxy services.

```shellscript
cd apps/backbonedocker compose up -d
```

| Service | Image | Internal Port | External Port | Role |
| --- | --- | --- | --- | --- |
|  |  | 27017 | 27017 | Primary data store for users, functions, and KV metadata [apps/backbone/docker-compose.yaml#2-9](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/backbone/docker-compose.yaml#L2-L9) |
|  |  | 80/443 | 80/443 | SSL Termination and routing via network mode [apps/backbone/docker-compose.yaml#25-34](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/backbone/docker-compose.yaml#L25-L34) |

### Environment Configuration

Services require environment variables for database connectivity and security. Create files in the respective app directories [memory-bank/techContext.md#84-118](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/memory-bank/techContext.md?plain=1#L84-L118)

Common Variables:

```env
MONGODB_URI=mongodb://[REDACTED_LOCAL_DEV_USER]:[REDACTED_LOCAL_DEV_PASSWORD]@localhost:27017JWT_SECRET=your_random_secret_stringNODE_ENV=development
```
