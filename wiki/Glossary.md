## Glossary

Relevant source files

This page provides technical definitions and code references for the domain-specific terms, architectural concepts, and abbreviations used throughout the PeerComp platform.

## 1\. Core Network Concepts

### Kademlia DHT

The distributed hash table (DHT) algorithm used for peer discovery and data routing. PeerComp uses a 256-bit ID space [apps/web/app/lib/peer/peer-node.ts#9](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/lib/peer/peer-node.ts#L9-L9)

- K-Bucket: A list containing up to $K=20$ known peers at a specific XOR distance range [apps/web/app/lib/peer/peer-node.ts#7-89](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/lib/peer/peer-node.ts#L7-L89)
- XOR Distance: The metric used to calculate the "distance" between two IDs (Node IDs or Keys) by applying the bitwise XOR operator on BigInt representations [apps/web/app/lib/peer/peer-node.ts#23-29](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/lib/peer/peer-node.ts#L23-L29)
- Alpha ($\\alpha$): The concurrency parameter (set to 3) defining how many parallel RPC requests are sent during iterative lookups [apps/web/app/lib/peer/peer-node.ts#8](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/lib/peer/peer-node.ts#L8-L8)

### PeerID / NodeID

A unique 64-character hexadecimal string (256 bits) identifying a participant in the network.

- Browser Nodes: Generated using and converted to hex [apps/web/app/lib/peer/peer-node.ts#13-20](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/lib/peer/peer-node.ts#L13-L20)
- Gateway Nodes: Uses a static or semi-static ID to provide stable entry points [apps/node-worker-gateway/node.ts#85-86](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/node-worker-gateway/node.ts#L85-L86)
- User ID: In the Org API, the model uses a generated 256-bit NodeID as its primary [packages/models/src/user.model.ts#11-13](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/packages/models/src/user.model.ts#L11-L13)

### RPC (Remote Procedure Call)

Peer-to-peer messages exchanged over WebRTC.

- PING: Verifies a node is still alive [apps/web/app/lib/peer/peer-node.ts#43](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/lib/peer/peer-node.ts#L43-L43)
- FIND\_NODE: Requests a list of peers closer to a target ID [apps/web/app/lib/peer/peer-node.ts#44](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/lib/peer/peer-node.ts#L44-L44)
- FIND\_VALUE: Requests a value associated with a key, or closer nodes if the value is not found [apps/web/app/lib/peer/peer-node.ts#45-47](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/lib/peer/peer-node.ts#L45-L47)
- STORE: Instructs a node to persist a key-value pair or function [apps/web/app/lib/peer/peer-node.ts#48](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/lib/peer/peer-node.ts#L48-L48)
- FUNCTION\_CALL: Executes a serverless function on a remote peer [apps/web/app/lib/peer/peer-node.ts#49](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/lib/peer/peer-node.ts#L49-L49)

## 2\. Infrastructure and Gateway

### GatewayNode

A Node.js implementation of the Kademlia protocol that acts as a bridge between standard HTTP/HTTPS traffic and the P2P network [apps/node-worker-gateway/node.ts#55](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/node-worker-gateway/node.ts#L55-L55) It handles wildcard subdomain routing via Nginx [apps/backbone/nginx/nginx.conf#79-88](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/backbone/nginx/nginx.conf#L79-L88)

### PeerSignal

The signaling server built on [apps/peer\_signal/peer-signal.ts#17](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/peer_signal/peer-signal.ts#L17-L17) It facilitates the WebRTC handshake (SDP/ICE exchange) by maintaining a registry of active peer IDs in a [apps/peer\_signal/peer-signal.ts#4-25](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/peer_signal/peer-signal.ts#L4-L25)

### BinaryPack

The serialization format used by PeerJS. The must use to communicate with browser-based peers [apps/node-worker-gateway/node.ts#17](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/node-worker-gateway/node.ts#L17-L17)

### SES (Secure EcmaScript)

A hardened JavaScript environment provided by Agoric. PeerComp uses it to execute untrusted user code with [packages/worker/src/worker.mjs#3-6](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/packages/worker/src/worker.mjs#L3-L6)

- Compartment: The isolation boundary where user code runs [packages/worker/src/worker.mjs#43](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/packages/worker/src/worker.mjs#L43-L43)
- secureFetch: A hardened wrapper around the global that implements SSRF protection [packages/worker/src/worker.mjs#26-41](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/packages/worker/src/worker.mjs#L26-L41)

## 3\. Storage and Encryption

### NodeMap

A hybrid storage class in the browser that combines an in-memory with persistent storage via [apps/web/app/lib/peer/peer-node.ts#102-222](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/lib/peer/peer-node.ts#L102-L222)

### ECDH (Elliptic Curve Diffie-Hellman)

The key agreement protocol (using the P-256 curve) used to derive a shared secret between two peers for encrypted KV storage [apps/web/app/lib/encryption/cryptoWebWorker.ts#43-55](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/lib/encryption/cryptoWebWorker.ts#L43-L55)

### AES-GCM

The authenticated encryption algorithm used to secure KV values. The (Initialization Vector) is stored alongside the encrypted payload in MongoDB [packages/models/src/kv.model.ts#17](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/packages/models/src/kv.model.ts#L17-L17)

### cryptoWebWorker

A dedicated Web Worker that offloads cryptographic operations (key generation, encryption, decryption) from the main UI thread to prevent blocking [apps/web/app/lib/encryption/cryptoWebWorker.ts#27-86](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/lib/encryption/cryptoWebWorker.ts#L27-L86)
