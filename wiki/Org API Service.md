## Org API Service (apps/org)

Relevant source files

The Org API Service serves as the central administrative and persistence layer for the PeerComp platform. It is a Node.js Express application responsible for managing user identities, serverless function definitions, and encrypted key-value storage metadata. While the platform utilizes a decentralized P2P network for execution, the Org API provides the necessary "Source of Truth" for account management and initial resource synchronization between the cloud and the local Kademlia node.

### System Role and Architecture

The service operates on port [apps/org/package.json#20](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/org/package.json#L20-L20) and connects to a MongoDB instance for persistent storage using Mongoose [apps/org/package.json#22](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/org/package.json#L22-L22) It exposes a RESTful API that is consumed by the web frontend and other infrastructure components.

Core Responsibilities:

- Identity Management: Handling user registration, login, and JWT issuance using [apps/org/src/services/user.service.ts#5](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/org/src/services/user.service.ts#L5-L5)
- Resource Catalog: Storing user-defined serverless functions that are later propagated to the Kademlia DHT.
- Metadata Persistence: Managing the storage of encrypted Key-Value pairs through [apps/org/src/services/kv.service.ts#9](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/org/src/services/kv.service.ts#L9-L9)
- Security Enforcement: Validating requests via a centralized authentication middleware and password hashing [apps/org/src/services/user.service.ts#52](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/org/src/services/user.service.ts#L52-L52)

### Authentication and Security

The Org API handles sensitive data using industry-standard security practices. User passwords are never stored in plain text; they are hashed using with 10 salt rounds [apps/org/src/services/user.service.ts#50-52](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/org/src/services/user.service.ts#L50-L52) Upon successful login, the service issues a JSON Web Token (JWT) signed with a environment variable, which expires in 7 days [apps/org/src/services/user.service.ts#113-117](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/org/src/services/user.service.ts#L113-L117)

Data validation is enforced across all services using Zod schemas. For example, validates complex password requirements (uppercase, lowercase, number, special character) during registration and profile updates [apps/org/src/services/user.service.ts#19-32](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/org/src/services/user.service.ts#L19-L32)

### Resource Domains

The API is divided into three primary domains, each managed by its own set of routes and services.

#### 1\. User Management API

Handles the lifecycle of user accounts, including registration, login, and profile management.

- Key Logic: [apps/org/src/services/user.service.ts#6](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/org/src/services/user.service.ts#L6-L6) and [apps/org/src/services/user.service.ts#94](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/org/src/services/user.service.ts#L94-L94)
- For details, see [User Management API](#3.1).

#### 2\. Functions API

Allows users to perform CRUD operations on serverless function definitions. These definitions include the JavaScript code and triggers that are eventually synced to the P2P network.

- Key Logic: Manages the defined in shared packages.
- For details, see [Functions API](#3.2).

#### 3\. Key-Value Storage API

Manages the storage of user data. This domain supports encryption metadata, storing fields like, (Initialization Vector), and buffers [apps/org/src/services/kv.service.ts#21-25](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/org/src/services/kv.service.ts#L21-L25)

- Key Logic: [apps/org/src/services/kv.service.ts#10](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/org/src/services/kv.service.ts#L10-L10) and [apps/org/src/services/kv.service.ts#83](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/org/src/services/kv.service.ts#L83-L83)
- For details, see [Key-Value Storage API](#3.3).
