## User Management API

Relevant source files

The User Management API is a core component of the service, providing the foundation for identity, authentication, and authorization across the PeerComp platform. It handles user registration, secure credential management using, and JWT-based session handling. A distinctive feature of this system is the generation of a unique 256-bit Node ID for every user, which serves as their identity within the Kademlia DHT network.

## User Data Model

The model represents the persistent identity of a participant.

### Node ID Generation

Unlike standard MongoDB ObjectIDs, the field is a custom 256-bit hexadecimal string. This ensures that the User ID is compatible with the XOR distance metrics used in the P2P network layer.

## Authentication Flow

The system utilizes JSON Web Tokens (JWT) for stateless authentication. The environment variable is used to sign tokens with a 7-day expiration [apps/org/src/services/user.service.ts#113-117](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/org/src/services/user.service.ts#L113-L117)
