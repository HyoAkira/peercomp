## PeerSignal Signaling Server (apps/peer\_signal)

Relevant source files

The PeerSignal service is a critical infrastructure component of the PeerComp network, acting as the meeting point for nodes to establish Peer-to-Peer (P2P) connections. It facilitates the WebRTC handshake (SDP and ICE exchange) and provides a discovery mechanism for nodes to find active peers in the network.

## Architecture Overview

The service operates two distinct servers within a single process:

1. PeerJS Signaling Server (Port 9000): Handles the low-level WebRTC signaling protocol using the library [apps/peer\_signal/peer-signal.ts#1-17](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/peer_signal/peer-signal.ts#L1-L17)
2. Discovery HTTP Server (Port 8000): A lightweight Node.js HTTP server that exposes an endpoint for fetching a list of currently connected Peer IDs [apps/peer\_signal/main.ts#12-38](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/peer_signal/main.ts#L12-L38)

## PeerSignal Implementation Details

The class serves as a wrapper around the from the package. It maintains a registry of active connections to facilitate peer discovery.

### Connection Management

Connections are tracked using a JavaScript object [apps/peer\_signal/peer-signal.ts#4](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/peer_signal/peer-signal.ts#L4-L4) When a client connects to the signaling path (), the server emits events that update this map:

- event: Triggered when a node establishes a WebSocket connection for signaling. The client's ID is stored in the map [apps/peer\_signal/peer-signal.ts#22-25](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/peer_signal/peer-signal.ts#L22-L25)
- event: Triggered when the WebSocket closes. The ID is removed from the map to ensure the discovery list remains fresh [apps/peer\_signal/peer-signal.ts#27-30](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/peer_signal/peer-signal.ts#L27-L30)

### Peer Discovery API

The companion HTTP server provides a simple REST-like interface for peer discovery. This is used by new nodes (both and ) to find initial entry points into the network [memory-bank/systemPatterns.md#84-90](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/memory-bank/systemPatterns.md?plain=1#L84-L90)

| Endpoint | Method | Description |
| --- | --- | --- |
