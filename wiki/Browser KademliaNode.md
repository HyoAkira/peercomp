## Browser KademliaNode (apps/web)

Relevant source files

The class is the core component of the browser-side peer-to-peer network. It implements a Distributed Hash Table (DHT) using the Kademlia protocol over WebRTC (via PeerJS). This node is responsible for peer discovery, distributed key-value storage, and executing remote function calls in a sandboxed environment.

## Kademlia DHT Implementation

The implementation follows the standard Kademlia specification with specific adaptations for the browser environment, such as using PeerJS for signaling and WebRTC for data channels.

### Identity and Distance Metric

Each node is identified by a 256-bit ID generated using [apps/web/app/lib/peer/peer-node.ts#13-20](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/lib/peer/peer-node.ts#L13-L20) The distance between two nodes is calculated using the XOR metric, which is implemented by converting hex strings to [apps/web/app/lib/peer/peer-node.ts#23-29](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/lib/peer/peer-node.ts#L23-L29)

### K-Buckets

Nodes are organized into objects, where is set to 20 [apps/web/app/lib/peer/peer-node.ts#7](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/lib/peer/peer-node.ts#L7-L7) There are 256 buckets (one for each bit of the ID space) [apps/web/app/lib/peer/peer-node.ts#236](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/lib/peer/peer-node.ts#L236-L236)

- Storage: Each bucket stores peer objects containing the peer ID and active connection [apps/web/app/lib/peer/peer-node.ts#70](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/lib/peer/peer-node.ts#L70-L70)
- Management: The method ensures unique entries and enforces the bucket limit [apps/web/app/lib/peer/peer-node.ts#73-80](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/lib/peer/peer-node.ts#L73-L80)

### Routing Table Logic

The maintains its routing table by calculating the bit-distance of a new node and placing it in the appropriate bucket [apps/web/app/lib/peer/peer-node.ts#314-319](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/lib/peer/peer-node.ts#L314-L319)
