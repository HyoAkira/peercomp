## User Panel: Functions and KV Management

Relevant source files

The User Panel provides an authenticated interface for users to manage their serverless functions and distributed key-value storage. It serves as the primary bridge between the centralized Org API and the decentralized Kademlia network by synchronizing user resources into the local node's store using cryptographic signatures for verification.

## Function Management

The allows users to perform CRUD operations on serverless functions. These functions are stored centrally in MongoDB via the Org API but are also propagated to the P2P network for distributed execution.

### Components and Implementation

- FunctionsPage: The main container that maps through the state from and renders function list items [apps/web/app/pages/panel/kv.tsx#61-73](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/pages/panel/kv.tsx#L61-L73)
- NewFuncModal: Handles function creation. It minifies the JavaScript code using [apps/web/app/pages/panel/components/newFuncModal.tsx#48-61](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/pages/panel/components/newFuncModal.tsx#L48-L61) calculates a namespace from the user's public key [apps/web/app/pages/panel/components/newFuncModal.tsx#67-68](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/pages/panel/components/newFuncModal.tsx#L67-L68) and performs a request to the API. After a successful response, it signs the payload and stores it in the local Kademlia node [apps/web/app/pages/panel/components/newFuncModal.tsx#106-118](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/pages/panel/components/newFuncModal.tsx#L106-L118)
- EditModalComponent: Provides a interface. It similarly minifies code [apps/web/app/pages/panel/components/editModal.tsx#67-84](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/pages/panel/components/editModal.tsx#L67-L84) and updates both the Org API and the P2P network using [apps/web/app/pages/panel/components/editModal.tsx#117-121](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/pages/panel/components/editModal.tsx#L117-L121)
- DeleteModalComponent: Removes functions from the Org API and the Kademlia network. It calculates the DHT key based on the namespace, type, method, and endpoint before calling [apps/web/app/pages/panel/components/deleteModal.tsx#30-33](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/pages/panel/components/deleteModal.tsx#L30-L33)

## Code Execution Sandbox

While the User Panel manages the storage of code, the actual execution is handled by sandboxed environments using SES (Secure EcmaScript).

- Browser Sandbox: uses and to execute functions within a Web Worker [apps/web/app/lib/peer/worker.js#1-6](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/lib/peer/worker.js#L1-L6)
- Gateway Sandbox: provides a similar environment for server-side execution of P2P function calls [apps/node-worker-gateway/worker.mjs#1-7](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/node-worker-gateway/worker.mjs#L1-L7)
- SSRF Protection: Both environments implement to prevent user code from accessing local network resources or private IP ranges [apps/web/app/lib/peer/worker.js#12-49](https://github.com/HyoAkira/bitirme2/blob/7a5d8555/apps/web/app/lib/peer/worker.js#L12-L49)
